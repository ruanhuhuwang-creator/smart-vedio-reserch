# SmartVision Windows 便携版使用说明

## 数量统计与停止分析

在“事件检索”中选择行人、汽车等类别，再使用类别下的“数量统计 / 出现时间段”菜单。
数量表示每个时间段采样帧中的最大同时出现数量；不是不同人员的累计人数，也未进行身份去重。
已有索引可直接查看数量，不需要重新分析。点击结果仍可跳转播放。

“开始分析”下的“停止分析”按钮仅在排队或执行时可用。运行中会先显示“正在停止”，
待当前推理/解码返回后安全取消；最终显示“已停止”。停止只影响当前任务，其他任务和软件继续运行。
原视频、上一次成功索引保留；当前未完成结果不发布，再次开始从头分析。

首次使用此版本会将数据库升级到 v3；已有 v1/v2 数据库在同目录自动保存 `.pre-v3.*.sqlite3` 备份。
升级保留视频、检测和任务历史。请先停止旧版本；旧 EXE 不支持新版数据库，不要交替启动新旧版本。

1. 将 ZIP **完整解压**到可读取的本地目录，保留 SmartVision.exe 和 `_internal` 的相对位置。不能只复制 EXE，也不能直接在 ZIP 里运行。
2. 双击 SmartVision.exe，等待控制窗口显示“服务已就绪”。程序会自动打开默认浏览器；也可点击“打开 SmartVision”。
3. 在网页导入 MP4/MOV/AVI，点击开始分析，完成后按 person/car 等类别检索，点击结果或时间轴跳转原视频。
4. 使用结束后，在应用控制窗口点击“停止并退出”或关闭窗口。有分析任务时会提示确认，等待窗口退出。

关闭浏览器标签不会停止应用；可由控制窗口重新打开。不需要安装 Python、Node.js 或 CUDA Toolkit，不需要运行命令。
仅监听 127.0.0.1，不向局域网开放；首选端口冲突时自动选择空闲端口。相同用户数据目录只允许启动一个实例。

## 系统要求

Windows 10/11 64 位、现代桌面浏览器、建议 16GB 内存及至少 12GB 可用磁盘（另需视频存储空间）。
可选兼容 NVIDIA GPU 和足够新的驱动；本包带 CUDA 12.8 的 PyTorch 运行库，但不带显卡驱动。
CUDA 不可用时自动使用 CPU并记录原因，CPU 分析速度较慢。无需系统 Python/Node 或手动启动服务。
本机已进行 CUDA 和禁用 CUDA 后的 CPU 验证；第二台无开发环境电脑未验证，详见 PHASE5_VALIDATION.md。

## 数据与日志

默认保存到 `%LOCALAPPDATA%\SmartVision`，与解压目录、当前工作目录分离：

- videos：上传的视频。
- smartvision.sqlite3：视频、索引及任务状态。
- outputs：输出预留目录。
- logs/smartvision.log：主要日志，自动轮转；console.log 收集第三方诊断输出。
- config、cache、tmp：用户设置与运行缓存。

重新启动保留视频和索引；移动程序文件夹不会移动或删除这些数据。
备份前先正常退出应用，再复制整个数据目录。请勿运行时直接替换数据库。
应用不会自动迁移或删除开发项目的 data、模型或数据库。

## 播放与离线使用

程序自带 YOLO26n 权重和 FFprobe，启动及分析无需联网。浏览器编码支持受容器/编码限制：
MP4/H.264 8-bit yuv420p，音频为 AAC/MP3 或无音轨；不兼容时显示明确提示，仍可分析和检索。
没有自动转码、剪辑导出或大模型服务。检测结果存在误检/漏检，不能视为绝对真值。

## 故障处理

启动失败时请保留错误提示，并点击“打开日志目录”查看日志。若提示资源缺失，请重新完整解压。
若提示已有实例，请先关闭原控制窗口；不要为了重启而删除数据库。
任务失败可查看网页错误及日志，既有有效索引不会被失败重建覆盖。
不要强制结束正在分析的进程；正常退出会中断未完成任务，重新启动后可由用户重新提交。
本测试包未做代码签名；校验 ZIP 随附 SHA256 后使用，勿更改系统安全设置来绕过未知来源检查。

源码及许可证随包提供：`源码与许可.md`、`_internal/licenses`、`_internal/frontend/dist/source-code.zip`。
# 升级与片尾时间戳提示

升级时先用旧版本控制窗口停止服务，再完整解压新版、启动其中的 SmartVision.exe。
现有视频和索引仍保存在同一用户数据目录，无需复制数据库或重新上传。
片尾 PTS 修复版会跳过极少量异常尾帧的索引记录并写入日志；视频中途或严重的时间戳异常仍会报告失败。
此前因 PTS 报错的视频可选择后重新分析，不需要转码或更改原文件。
